A portfolio series exploring agentic AI patterns, one lab at a time. Each lab isolates a single pattern in a small, runnable project.

Lab 01 · Reflection

Self-critiquing chart agent

A cheap model drafts matplotlib code from an English request, exec() renders the chart, a stronger model looks at the rendered pixels (not the code) and rewrites. Reflection over an image artifact.

Self-critiquing SQL agent

Same loop, different artifact: cheap model drafts SQL from an English question, SQLite runs it, the critic judges the rows that came back. Ships two critic variants so you can see what grounded feedback catches that code-review alone misses.

About the series

Every lab follows the same skeleton — make_data.py for a seeded synthetic dataset, utils.py for LLM plumbing, a short workflow file, and a self-contained index.html dashboard — so patterns are easy to compare across labs.

Code is at github.com/ArunaSivaram/agentic-ai-labs. Each lab has its own README with run instructions.
